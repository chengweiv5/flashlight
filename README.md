# Flashlight

面向华为 Mate 60 Pro、HarmonyOS 4.2.0 Android 兼容环境的自用照明应用。

**当前阶段：产品设计。尚未开始应用开发，没有可安装的 APK。**

## 已确认的设计

- 一个首页，提供「手电筒」和「柔光灯」两个模式。
- 手电筒使用后置 LED；柔光灯使用手机屏幕。
- 普通打开 App 不自动亮灯，点击大按钮后开启。
- 提供独立的桌面「一键开灯」快捷入口。
- 关灯时切换模式不亮灯；亮灯时切换模式会切换光源，默认不同时开启两种光源。
- 柔光灯支持白光、暖光、亮度调节，并记住上次的颜色和亮度。
- 后置手电筒以熄屏后可靠照明、真实状态同步为重点验收项。
- 后置 LED 调光先验证真机能力，支持才提供，不用快速闪烁模拟调光。
- 不做延迟关灯和定时关闭。

## 使用原则

纯离线、无广告、无账号、最少必要权限；普通界面采用深色主题，避免启动时白屏。
